# Codex 切换器 · 图标迭代记录

> 目标：为「Codex 切换器」重做一个能表达「切换 / 转换」的程序图标。
> 要求：带 Codex 视觉基因但**不能**与官方 Codex 图标雷同；16 / 32 / 48 / 256
> 各尺寸清晰；深色与浅色桌面背景下都能辨认。
> 产出：`assets/icon.ico`（7 档尺寸）+ `assets/icon-*.png` + 预览图。
> 渲染脚本：`tools/make_icon.py`（全部参数化，可复现每一轮）。

---

## 一、设计母题

| 要素 | 取法 | 说明 |
|---|---|---|
| 品牌色 | Codex / OpenAI 青绿 `#10A37F` 为基准 | 只取「色相基因」，不复制官方图标的黑白极简构图 |
| 底座 | 圆角方形（squircle） | 桌面图标通用容器，缩到 16px 仍是一个完整实体 |
| 主体 | 上下两条**反向**胶囊箭头 | 「A ↔ B 互换」的通用语汇，一眼读出「切换」 |
| 边界 | 深色外描边 + 顶部高光 + 底部内阴影 + 内圈亮边 | 深色背景下靠亮底座、浅色背景下靠深描边，双向保底 |

刻意规避：不使用官方 Codex 的黑白单色、不使用 `</>`、不使用终端窗口造型 ——
避免与官方图标混淆，同时把「切换」这件事放在画面正中央。

## 二、20 轮迭代明细

| 轮次 | 具体调整点 | 解决的问题 / 验证结论 |
|---|---|---|
| r01 | 纯色 `#10A37F` 圆角 6%、平头粗箭头、无描边无渐变 | 先确认「双向箭头＝切换」母题成立；缺点是扁平、方角生硬、浅色背景下轮廓发飘 |
| r02 | 圆角 6% → 14% | 去掉方角硬感，向 squircle 靠拢，视觉重量更集中 |
| r03 | 纯色 → 垂直渐变 `#10A37F → #0A7F5F` | 消除塑料感，底座有了上亮下暗的体积 |
| r04 | 顶部提亮到 `#1ECB98` | 深色桌面下更跳；实测浅色桌面仍缺轮廓 |
| r05 | 加 3% 深色外描边 `#064E3B` | **解决浅色桌面轮廓发飘**——浅底靠深边、深底靠亮身，双向可辨 |
| r06 | 箭头杆改胶囊圆头（capsule） | 平头显得粗糙；圆头与现代系统图标语言一致 |
| r07 | 箭头瘦身：厚 0.11→0.095、头长 0.16、头宽比 1.8 | 由「粗笨」转为「精悍」，箭头方向感由头宽比承担 |
| r08 | 两箭头中心间距 0.20 → 0.30 | **解决 32px 下两条箭头糊成一坨**，中间留出通透负空间 |
| r09 | 箭头加柔和投影（黑 18%、下移 1%、模糊 1.2%） | 白箭头压在亮绿底上边缘发虚，投影把它「按」在底座上 |
| r10 | 顶部内高光（白 22%） | 补一层玻璃质感，256px 下不再是一块死色 |
| r11 | 外留白 5% → 3.5% | 主体占比 84%→90%，同尺寸下图形更饱满 |
| r12 | 底部内阴影（黑 12%） | 底座下缘在浅色背景下不再「浮」起来 |
| r13 | 加内圈亮边（白 14%、1px 级） | 玻璃边缘感；浅色背景下多一道内亮线，轮廓更立体 |
| r14 | 新增 small 分支（≤48px）：关高光/阴影/投影，描边加粗到 4.5%，箭头加厚 | 小尺寸下高光与投影会变成脏点，必须减法处理 |
| r15 | 描边压深到 `#053F30`、顶部提到 `#24D9A2` | 拉开明暗层次，白箭头的对比度同步上升 |
| r16 | 16px 实测偏挤：小尺寸描边收 3.8%、箭头 0.135、间距 0.32、头宽比 1.65 | 16px 画布里描边占比过高会「吃」掉内部空间 |
| r17 | 超采样 4x→8x（16/32 用 12x） | 斜边与圆角出现锯齿毛刺，提高超采样后边缘干净 |
| r18 | 大尺寸圆角 18%→22%、高光衰减区间 0.45→0.50 | 256px 下过渡更柔，圆角比例更接近现代 app icon |
| r19 | 逐尺寸单独配参（32 间距 0.31 / 48 间距 0.29、描边 4%、头宽比 1.7） | 一套参数走天下会在某一档崩；改为按尺寸调 |
| r20 | 头宽比 1.72→1.78 更锋利、箭头长 0.60、投影收到 16% | 定稿：箭头尖端更锐，白块面积略收，整体更「利」 |

演进全程可视化见 `assets/evolution.png`（每格 96px 渲染）。

## 三、逐尺寸适配策略

不同尺寸不是简单缩放，而是**分别配参、分别渲染**（`SIZE_TWEAK` 表）：

| 尺寸 | 模式 | 描边 | 箭头厚 | 间距 | 头宽比 | 超采样 |
|---|---|---|---|---|---|---|
| 16 | 简化（无高光/阴影/投影） | 4.4% | 0.115 | 0.40 | 2.00 | 12x |
| 24 | 简化 | 4.2% | 0.118 | 0.38 | 1.95 | 12x |
| 32 | 简化 | 4.0% | 0.115 | 0.36 | 1.90 | 12x |
| 48 | 简化 | 3.8% | 0.120 | 0.33 | 1.80 | 10x |
| 64 | 完整 | 3.6% | 0.120 | 0.30 | 1.78 | 8x |
| 128 | 完整 | 3.4% | 0.115 | 0.30 | 1.78 | 8x |
| 256 | 完整 | 3.4% | 0.115 | 0.30 | 1.78 | 6x |

关键取舍：
- **16px 靠「拉大间距 + 加大头宽比」保箭头尖**。早期把杆做粗（0.15）反而让箭头尖消失，
  因为杆厚接近头高，尖端只剩 1.5px 的凸起；改成杆 0.115 / 头宽比 2.0 后，尖端凸起约 2px，可辨。
- **小尺寸一律关掉高光与投影**：半像素级的白/黑叠加在 16px 会变成脏边。
- **256 用 6x 超采样即可**，8x 只会增加耗时，肉眼无差；小尺寸反而需要 12x 才能压住锯齿。

## 四、深色 / 浅色背景验证

| 背景 | 保底手段 | 结论 |
|---|---|---|
| 深色桌面（`#16181C` 附近） | 底座本身是高明度青绿（顶 `#22D49E`） | 主体清晰，描边虽暗但被亮底座托住，不影响识别 |
| 浅色桌面（`#F2F3F5` 附近） | 深色外描边 `#053F30` + 底部内阴影 + 内圈亮边 | 轮廓不糊，底座与背景有明确分界 |

对比图：`assets/preview-desktop.png`（48/32/16 三种桌面真实尺寸，上下深浅两版）
尺寸总览：`assets/preview-sizes.png`（16→256，深浅两版）

## 五、最终规格

- 底座渐变：`#22D49E`（顶）→ `#0A7454`（底）
- 外描边：`#053F30`
- 箭头：纯白 `#FFFFFF`
- 内圈亮边：白 14%
- 圆角：22%（底座边长）
- 外留白：3.2%

## 六、如何重新生成

```bash
# 需要 Pillow
python tools/make_icon.py assets
```

会重写 `assets/icon.ico`、`assets/icon-*.png`、`assets/preview-*.png`、`assets/evolution.png`。
调整 `REVISIONS`（每轮参数）或 `SIZE_TWEAK`（逐尺寸微调）即可继续迭代。
